# 📝 Smart Todo

A modern and responsive Todo Application built with React to practice real-world React concept and application development.

## 🚀 Features

- Add new todos
- Edit todos
- Delete todos
- Mark todos as completed
- Search todos
- Filter todos by All, Active and Completed
- Save todos using Local Storage
- Responsive design
- Modern UI with Tailwind CSS

## 🛠️ Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- HTML
- Font Awesome

## 📚 Concepts Practiced

- Components
- Props
- useState
- useEffect
- Event Handling
- Forms
- Conditional Functionality
- Local Storage
- State Management
